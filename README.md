# Qadam AI — ИИ-карьерный помощник для студентов ЕНУ

Проект для конкурса «ЖИ-әзірлемелер» (ЕНУ им. Л.Н. Гумилёва, 2026).

**Qadam AI** помогает студентам, магистрантам и докторантам сделать первый шаг в карьеру. Интерфейс на казахском, русском и английском.

## Возможности

1. **Профиль навыков.** ИИ анализирует резюме или транскрипт из Platonus (PDF/TXT) и выделяет профессиональные и гибкие навыки, языки и подходящие направления. По транскрипту он также составляет черновик резюме.
2. **Подбор стажировок.** Топ-5 вакансий с процентом совпадения и объяснением.
3. **Анализ недостающих навыков.** Каких навыков не хватает для каждой вакансии и как их освоить.
4. **Тренажёр собеседования.** 5 вопросов под выбранную вакансию, отзыв на каждый ответ и итоговая оценка.
5. **ИИ-парсер вакансий для карьерного центра.** Вставляете текст любой вакансии, ИИ структурирует её и добавляет в базу.

## Технологии

- Python, Streamlit (веб-интерфейс)
- Google Gemini API (LLM): анализ документов, семантическое сопоставление, генерация и оценка ответов, структурированный вывод JSON
- pypdf: чтение PDF

## Безопасность и персональные данные

- Загруженные файлы не сохраняются: они обрабатываются в памяти только во время анализа.
- API-ключ хранится в Streamlit Secrets, а не в коде.
- Защита от prompt injection: ИИ получает инструкцию считать содержимое документов только данными и игнорировать команды внутри них.

## Запуск локально

```bash
pip install -r requirements.txt
# создайте файл .streamlit/secrets.toml со строкой:
# GEMINI_API_KEY = "ваш_ключ"
streamlit run app.py
```

## Интеграция в SMART.ENU (план)

- Раздел «Мансап / Карьера» в личном кабинете студента.
- Автоматическое получение транскрипта из Platonus вместо ручной загрузки.
- Подключение API hh.kz и базы партнёров карьерного центра ЕНУ.
- Аналитика для университета: каких навыков не хватает студентам относительно рынка труда.

## Данные

`vacancies.json` — демонстрационная база из 30 типовых стажировок. Работодатели в ней обобщены и помечены «(демо)». Реальные вакансии добавляются через ИИ-парсер с указанием источника.
